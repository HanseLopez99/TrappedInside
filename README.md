# 🏚️ Trapped Inside

**Trapped Inside** es un juego de terror psicológico tipo *escape room* desarrollado en **Unity**.  
El jugador despierta en una casa desconocida y debe explorar, interactuar con el entorno y resolver puzzles ambientales para poder escapar, mientras la casa reacciona a sus acciones.


---

## 🎮 Gameplay

- Exploración en **primera persona**
- Resolución de puzzles ambientales
- Interacción con objetos mediante raycast
- Uso de sonido, iluminación y UI para generar tensión
- Flujo completo: menú principal → juego → pausa → final

---

## 🧩 Características implementadas

- ✔️ Menú principal (Play / Options / Quit)
- ✔️ Menú de pausa (Resume / Restart / Main Menu / Quit)
- ✔️ Menú de opciones con control de volumen
- ✔️ Sonido ambiental y música de fondo
- ✔️ Efectos de sonido (pasos, linterna, alarmas, interacciones)
- ✔️ Sistema de interacción por Raycast
- ✔️ Puzzle de llave y estantería secreta
- ✔️ Puerta con bloqueo narrativo
- ✔️ Pantalla de victoria y pantalla de muerte
- ✔️ Gestión correcta del cursor e input FPS
